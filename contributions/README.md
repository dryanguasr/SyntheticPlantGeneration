# Contribuciones preservadas

Esta carpeta conserva entregas externas o estudiantiles que son relevantes
para el proyecto, sin confundirlas con la implementacion vigente bajo `src/`.

Cada contribucion debe incluir:

- autoria y procedencia;
- hash o referencia de la entrega recibida;
- alcance reproducible y limitaciones conocidas;
- exclusiones explicitas de datasets, pesos y resultados generados.

El codigo aqui preservado no define por si solo la arquitectura morfologica de
uchuva. Las implementaciones vigentes permanecen en `src/uchuva_lsystem/`.
