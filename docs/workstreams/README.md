# Frentes de trabajo

El repositorio se organiza en tres frentes interoperables. Son lineas de
desarrollo, no ramas de Git:

1. [Aumentacion clasica](classical_augmentation.md).
2. [Generacion sintetica](synthetic_generation.md).
3. [Puente hacia Gazebo](gazebo_bridge.md).

La arquitectura y el contrato entre ellos se describen en
`docs/architecture/integracion_augmentacion_sintetica_gazebo.md`.
